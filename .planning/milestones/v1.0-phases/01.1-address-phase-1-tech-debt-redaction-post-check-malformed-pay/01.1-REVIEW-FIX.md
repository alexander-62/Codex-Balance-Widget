### WR-01a: Blanket exception handler in `main()` bypasses the redaction-clean guarantee

**Files modified:** `probe_wham_usage.py`
**Commit:** 35ccbc7
**Applied fix:** The new `except Exception as exc:` handler in `main()` (added by
this phase to close the prior WR-01 finding) previously printed
`f"Непредвиденная ошибка: {exc}"` directly to stdout with no redaction guard,
unlike every other output path in this module. Mirrored the existing
`redaction_clean()` guard pattern used elsewhere: the exception message is now
built into a local `message` string, checked with `redaction_clean(message)`,
and replaced with a generic "сообщение скрыто по соображениям безопасности"
placeholder if the post-check fails, before being printed. `traceback.print_exc()`
under `--debug` is unchanged (debug tracebacks were already an accepted,
opt-in exception per the module's existing design).
