# Quick Plan: Show Codex Usage Limit Resets

## Objective

Show how many usage limit reset credits are available in the Codex balance widget, directly below the existing credits row. Include expiry text when the data source provides it.

## Implementation

1. Extend `probe_wham_usage.extract_fields()` with reset credit fields from `rate_limit_reset_credits`.
2. Extend `Balance` and JSON/text mapping in `codex_balance_widget_chrome.py`.
3. Add a compact reset credits UI row below credits.
4. Persist reset credit data in `codex_balance_history.json` entries so last-known data restores after launch.
5. Add focused tests for JSON extraction, Balance mapping, and Chrome text parsing.

## Acceptance

- Live/current JSON with `available_count: 2` displays reset credits as available.
- Missing `rate_limit_reset_credits` does not break existing parsing.
- Optional expiry text is shown when present in Chrome fallback text or a future JSON payload.
- Existing tests pass.
