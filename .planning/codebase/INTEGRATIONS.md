# External Integrations

**Analysis Date:** 2026-06-17

## APIs & External Services

**Browser-Scraped Web Page:**
- ChatGPT Codex usage page - The widget opens and reads visible text from `https://chatgpt.com/codex/cloud/settings/analytics#usage` to extract 5-hour limits, weekly limits, reset times, and credits.
  - SDK/Client: Playwright Python via `playwright.async_api` in `codex_balance_widget_chrome.py`.
  - Auth: Browser session stored by Google Chrome in `codex_chrome_profile/`; no API key or bearer token is configured in repository files.
  - Entry point: `CODEX_USAGE_URL` constant and `CodexUsageBrowser._fetch_once()` in `codex_balance_widget_chrome.py`.

**Local Browser Runtime:**
- Google Chrome - The app controls the locally installed Chrome executable using Playwright persistent contexts.
  - SDK/Client: `playwright.chromium.launch_persistent_context()` in `codex_balance_widget_chrome.py`.
  - Auth: Chrome profile cookies under `codex_chrome_profile/Default/Cookies` or `codex_chrome_profile/Default/Network/Cookies`; `has_saved_chrome_session()` checks only for file existence.
  - Configuration: Optional `CHROME_PATH` environment variable in `codex_balance_widget_chrome.py`; fallback paths are common Windows Chrome install locations.

**Windows Desktop Shell:**
- Windows Script Host - `run.bat` starts `run_hidden.vbs`, which launches `codex_balance_widget_launcher.pyw` with `pyw.exe -3`.
  - SDK/Client: `WScript.Shell` and `Scripting.FileSystemObject` in `run_hidden.vbs`.
  - Auth: Not applicable.
- Windows kernel and shell APIs - `codex_balance_widget_chrome.py` uses `ctypes` for process activation events, `msvcrt` for lock files, and `os.startfile` for opening logs.
  - SDK/Client: Python standard library in `codex_balance_widget_chrome.py`.
  - Auth: Not applicable.

## Data Storage

**Databases:**

  - Connection: Not applicable.

**File Storage:**
- Local filesystem only.
  - `codex_chrome_profile/` - Dedicated Chrome profile storing ChatGPT session state; ignored by `.gitignore`.
  - `codex_balance_widget_settings.json` - User settings written by `SettingsStore` in `codex_balance_widget_chrome.py`; ignored by `.gitignore`.
  - `codex_balance_history.json` - Usage samples written by `HistoryStore` in `codex_balance_widget_chrome.py`; ignored by `.gitignore`.
  - `widget_launch.log` - Runtime log written by `write_log()` in `codex_balance_widget_chrome.py` and `codex_balance_widget_launcher.pyw`; ignored by `.gitignore`.
  - `codex_balance_widget.lock` - Single-instance lock file used by `acquire_app_lock()` in `codex_balance_widget_chrome.py`; ignored by `.gitignore`.
  - `Codex*.mhtml` - Local diagnostic snapshots excluded by `.gitignore`.

**Caching:**
- Chrome profile cache and cookies are managed by Google Chrome under `codex_chrome_profile/`.
- Usage history is retained locally in `codex_balance_history.json`; `HistoryStore.append_balance()` in `codex_balance_widget_chrome.py` keeps recent entries and drops entries older than 21 days.

## Authentication & Identity

**Auth Provider:**
- ChatGPT web session through Google Chrome.
  - Implementation: On first launch or session expiry, `CodexUsageBrowser.fetch()` in `codex_balance_widget_chrome.py` opens visible Chrome and waits for the user to log in; later refreshes use headless Chrome with the same persistent `codex_chrome_profile/`.
  - Credentials: The widget never asks for credentials inside the app, as documented in the module header of `codex_balance_widget_chrome.py`.
  - Session detection: `has_saved_chrome_session()` in `codex_balance_widget_chrome.py` checks for Chrome cookie database files under the dedicated profile.
