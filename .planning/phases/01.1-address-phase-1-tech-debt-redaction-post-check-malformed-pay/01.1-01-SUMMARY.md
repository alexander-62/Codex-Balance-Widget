## Accomplishments
- `collect_windows()` no longer raises `AttributeError` when `rate_limit` or an `additional_rate_limits[]` entry is a truthy non-dict value — malformed entries are now treated as absent, exactly like the existing None/missing-key handling (CR-02).
- `main()`'s stdout JSON print is now verified by `redaction_clean()` before printing, mirroring `write_fixture()`'s existing guard — if the check fails, `ProbeError` is raised and nothing unredacted reaches stdout (CR-01).
- `main()` now converts ANY exception raised inside its try block (not just `ProbeError`) into the single clean-diagnostic contract — exit 1, one printed message, no raw traceback unless `--debug` (WR-01).
- Full unit test suite: 37 tests (33 pre-existing + 4 new), all passing, no network access.
