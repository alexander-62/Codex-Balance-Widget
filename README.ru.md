# Codex Balance Widget

[English](README.md)

Небольшой Windows-виджет для просмотра лимитов Codex Usage. Он открывает страницу
`https://chatgpt.com/codex/cloud/settings/analytics#usage` через установленный
Google Chrome и показывает остаток лимита в отдельном окне и системном трее.

## Возможности

- 5-часовой и недельный лимиты, время сброса и кредиты
- цветная трей-иконка с крупной цифрой-десятком
- tooltip с точными значениями
- локальный недельный график расхода
- настройка интервала обновления, режима поверх окон и языка интерфейса
- отдельный Chrome-профиль: основной профиль браузера не используется

## Требования

- Windows
- Python 3.10 или новее с Windows Python Launcher
- Google Chrome
- доступ к странице Codex Usage в аккаунте ChatGPT

## Установка и запуск

1. Запустите `install.bat`.
2. Запустите `run.bat`.
3. При первом старте войдите в ChatGPT в открывшемся Chrome.

Скачивать отдельный Playwright Chromium не нужно: приложение использует системный
Google Chrome.

## Трей

Цвет фона показывает состояние 5-часового лимита:

- зелёный: осталось `51–100%`
- оранжевый: осталось `21–50%`
- красный: осталось `0–20%`
- серый с `?`: данные ещё не получены

Эта же цветовая шкала используется везде, где показаны проценты остатка:
трей-иконка, числовые значения, линейные индикаторы и сегменты недельного burndown.

На иконке отображается крупная цифра-десяток: например, `87%` показывается как `8`.
Для `100%` отображается `✓`. Точные значения доступны при наведении курсора.

Крестик скрывает окно в трей. Для полного завершения используйте пункт `Exit` /
`Выход` в меню трей-иконки.

## Локальные данные

Приложение создаёт отдельный профиль `codex_chrome_profile`. В нём хранится
локальная сессия ChatGPT. Профиль, настройки, история и лог исключены из Git через
`.gitignore`. Не публикуйте и не передавайте папку профиля другим людям.
Перед каждым обновлением виджет очищает кэш-папки Chrome внутри этого профиля и
запускает Chrome с небольшими лимитами дискового и медиа-кэша. Cookies и
хранилище входа не удаляются, поэтому сессия ChatGPT должна сохраняться, а
профиль будет расти заметно меньше.

## Настройки

Доступны English и Русский. По умолчанию используется английский язык. После
смены языка перезапустите приложение.

Если Chrome не найден автоматически, задайте `CHROME_PATH`:

```bat
set CHROME_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
py -3 codex_balance_widget_chrome.py
```

## Ограничения

Это неофициальный инструмент, не связанный с OpenAI. Он читает видимый текст
страницы Codex Usage. Если интерфейс страницы изменится, парсер может потребовать
обновления.
